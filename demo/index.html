@pranen/activelook – demos

Small pages that drive ActiveLook glasses (e.g. ENGO 3) straight from the browser over Web Bluetooth.

Needs Chrome or Edge on desktop/Android, or the Bluefy browser on iPhone (Safari has no Web Bluetooth). Add ?mock to a demo URL to try it without glasses, ?debug to log every frame.

  • Hello
    Text with rotation, font and position; test grid of the visible area.
  • Assets
    Icons, layouts and animations built into every ActiveLook device, no upload needed.
  • Storage
    Configurations, images (stored and streamed), gauges, layouts and pages kept on the glasses.
  • Calibrate
    Find the visible area of your glasses with a ruler and adjustable edges; check text placement.
  • Input
    Touch and gesture events, plus queries: firmware, settings, battery, fonts.
  • Colors
    All 81 red-green colors, one by one or as a grid.
  • Clock
    Live clock with date, colored battery level and a seconds bar.
  • App
    Several screens, paged with the temple button via ScreenPager.
