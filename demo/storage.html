6. Browse a configuration

Selects a configuration (e.g. the ENGO app's "Engo") and steps through its images and fonts on the glasses – images cannot be read back, only shown. Selecting does not change a configuration. "Back to system configuration" restores the default; the ENGO app selects its own again when it connects.

The glasses list at most 105 images. Others can still be shown by id: enter the id and the size the image is stored with and press Show. The glasses cannot scale images – the size is only used to place the image on the mirrored display, so a wrong size just shifts it.
